# Geometry Dash mods

Two Geode mods for Geometry Dash 2.2091 on Geode 6.0.0-alpha.2. Free and open source (MIT).

| Folder | Mod |
| --- | --- |
| `frame-window-counter/` | Load a macro (.gdr, .gdr2, .slc, GDR .json), count the frame window of every input, show them as circles with a tally, and render to video. |
| `auto-deco/` | One-click fill, outline and glow for selected blocks in the editor. |

Each folder has its own README.

## Builds

Every push builds both mods for Windows with GitHub Actions. The `.geode` files are attached to the run (Actions tab) and committed to the `builds` branch. Copy them into `geode/mods` in your Geometry Dash folder.
